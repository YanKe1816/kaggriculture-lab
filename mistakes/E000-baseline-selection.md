# E000：不能用 Notebook 标题或历史 Top-10 标签选基线

- 局面：四个公开高票/高胜率策略需要决定首次提交者。
- 表面误区：`Top-10`、`40/40`、`74.5%` 来自不同时间、对手集和评测口径，不能直接横比。
- 现实证据：相同引擎、双方换边后，Router 对 Fast Routes 在 seeds 0–2 为 6-0；对另外两个候选在 seed 0 均为 2-0。平均金币优势为 9,260 至 23,448.5。
- 正确归因：先前标签的评测分布不同，标题不是当前环境中的可比证据。具体策略级失败原因仍待回放逐项验证，当前不做过度归因。
- 处理：首次提交选择 Router，而不是选择标题中名次最高者。
- 副作用：单 seed 可能过拟合，尚不能淘汰其他路线中的机制。
- 固定回归：后续候选必须用 `tools/evaluate.py` 在相同种子、双方换边后与当前 Router 比较；中闸门至少扩展多个种子。
