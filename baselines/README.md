# Public baselines

These agents were reproduced from public Kaggle competition notebooks on 2026-09-08:

- `router`: Thomas Tschinkel, “Kaggriculture: Public State Router (74.5% Win Rate)”.
- `fast-routes`: Kaito Fukami, “40/40 Early Floor | 39/46 Top-10 | v48 Fast Routes”.
- `v16`: boatlee, “V16-RC5 | High-Score 8C/4S Premium Market Lead”.
- `pasture`: Indar Karhana, “Shape the Shop Work the Pasture (TOP 10)”.

They are retained as reproducible opponents and attribution references. Competition code publicly shared through Kaggle is subject to the competition's public-code license terms. `main.py` at the repository root is currently identical to `router/main.py`.
